## 0. 결론 먼저

**축을 3개로 분리하고, 각 축을 서로 다른 장치에 태운다.**

| 축 | 무엇 | 어디에 태우나 | 시점 |
|---|---|---|---|
| **1. 상품 타입** | ブラ / ショーツ / インナー / レッグ / ホームウェア | **GNB + 컬렉션** | MVP |
| **2. 원단·기능** | モダール / コットン / 発熱 / シームレス … | **컬렉션** (교차 진입) | Phase 1.5 |
| **3. 속성** | 사이즈 · 컬러 · 컵 · 기능 | **필터** (메타필드) | Phase 1.5 |

현행 카페24는 이 3축이 **51개 카테고리 한 트리에 뒤섞여 있다.** 그래서 목록이 길고,
같은 상품이 어디에 있어야 하는지 매번 판단이 필요하다. Alo 는 같은 3축을 쓰되 **장치를 분리**했다.

## 1. 현행 카페24 — 무엇이 문제인가

51개 (대분류 13 / 하위 38). 문제는 개수가 아니라 **성격이 다른 것들이 형제 레벨에 있다는 점**이다.

| 성격 | 해당 카테고리 | 개수 |
|---|---|---|
| 상품 타입 | 브라 310 · 팬티 302 · 이너 315 · 레그 320 · 홈웨어 323 (+하위 20) | 25 |
| **서브브랜드** | ILLUIN 948 · NUKKNUKK 288 · SCHIER 284 · FREEPLE 285 · DO.FREE 286 · SMOOVE 289 · FZIMA 287 · HEATTOUCH 290 · DISNEY 512 | 9 |
| **원단** | 그린라벨 434 → 오가닉코튼 435 / 모달 436 / 코튼 437 / 인견 439 | 5 |
| **판매 상태** | 베스트 291 → 주간 292 / 리뷰 294 / 인기PICK 295 / 아울렛 297 · 신제품 378 | 6 |
| **프로모션** | 마리페 968 (+하위 5) | 6 |
| **속성** | 빅사이즈 298 | 1 |
| **대상** | 맨즈 327 | 1 |
| 기타 | 악세서리 797 | 1 |

`쉬어 브라 커브넥 텐션윙` 한 상품이 브라 · 심리스 · 서브브랜드 · 그린라벨 · 베스트 · 신제품에
동시에 속할 수 있다. **소속을 사람이 매번 정해야 하고, 정하는 사람마다 다르게 정한다.**
`2065` 일루인 홀터넥 브라에 조거팬츠·냉장고바지 태그가 붙어 있는 것(P1-5)이 그 증상이다.

## 2. Alo Yoga — 실측한 구조

> **한계 명시**: 사이트 직접 접근이 네트워크에서 차단돼, 아래는 **컬렉션 URL 패턴과 검색 메타데이터**로
> 역추적한 것이다. 렌더된 메가메뉴를 본 것이 아니다. 메뉴 라벨·정렬은 재확인이 필요하다.

### 확인된 컬렉션

| 유형 | 핸들 | 성격 |
|---|---|---|
| 진입 | `shop-all` · `womens-shop-all` | 전체 (필터 전제) |
| 진입 | `new-arrivals` · `bestsellers` · `back-in-stock-2` | 판매 상태 |
| **원단** | `airbrush` · `alosoft` · `airlift` | **franchise = 원단** |
| 편집 | `the-classics-collection` | 큐레이션 |
| 용도 | `yoga` | 활동 |
| 레거시 | `bras-1` (제목 "Bras (old)") | **폐기 미처리** |

### 세 가지 핵심 장치

**① 원단이 1차 머천다이징 축이다**
`airbrush`(고압박) · `alosoft`(기모 소프트) · `airlift`(경량)가 각각 컬렉션이고,
`/pages/fabrication-guide` 라는 **해설 페이지가 축을 떠받친다.**
고객은 "레깅스"가 아니라 "Airlift 레깅스"를 사러 온다.

**② 상품 타입은 컬렉션이 아니라 필터다**
```
/collections/shop-all?color=black&product-type=leggings&product-type=other-bottoms
```
`product-type` 이 **쿼리 파라미터**다. 타입별 컬렉션을 따로 만들지 않는다.

**③ 교차는 태그 경로로 만든다**
```
/collections/alosoft/leggings
/collections/airlift/shorts
```
Shopify 기본 기능 `/collections/{handle}/{tag}` 다. **앱도 커스텀 개발도 필요 없다.**
원단 N × 타입 M 을 컬렉션 N×M 개로 만들지 않고 **N개 컬렉션 + 태그**로 해결한다.

### 그대로 따라 하면 안 되는 것

- **`bras-1` "Bras (old)"** — Alo 조차 컬렉션 폐기 규칙이 없다. 우리는 처음부터 만든다 (§6).
- **원단 축은 Alo 라서 되는 것이다.** Alo 는 **브랜드가 하나**고 원단이 유일한 변별점이다.
  마른파이브는 서브브랜드가 9종이다. 둘 다 축으로 쓰면 **51개 문제를 일본어로 재현한다.**

## 3. 제안 — 3축 분리

### 1축 · 상품 타입 = GNB (MVP, `CLAUDE.md` §12 유지)

```
ブラ / ショーツ / インナー / レッグ / ホームウェア / サイズガイド / 配送状況
```

- Alo 는 타입을 필터로 내렸지만 **우리는 컬렉션으로 유지한다.** 이유는 관세다.
  レッグ 안에서 스타킹(과세)과 양말(면세)이 갈리고(`03-jp-tax-duty.md`),
  이 구분이 **가격 표시와 번들 설계에 직접 들어간다.** 필터로 내리면 이 경계가 흐려진다.
- `321 스타킹` / `322 양말` **분리 유지**는 이 때문이다. 통합하지 말 것.
- **`ホームウェア` 는 현재 비어 있다** — MVP 41 SKU 에 해당 품목이 없다.
  공개 전 상품을 넣거나 메뉴에서 뺀다.

### 2축 · 원단·기능 = 컬렉션 (Phase 1.5)

Alo 의 `airbrush`/`alosoft`/`airlift` 자리에 들어갈 후보:

| 컬렉션 | 근거 | 카페24 출처 |
|---|---|---|
| `modal` モダール | 그린라벨 436 | 이미 운영 중 |
| `cotton` コットン | 그린라벨 437 | 이미 운영 중 |
| `seamless` シームレス | 브라 311 | 이미 운영 중 |
| `heat` 発熱 | HEATTOUCH 290 | 이미 운영 중 |

**이 축은 MVP 에 넣을 수 없다.** 소재 조성비가 전 SKU 미확보 상태(P0)이고,
근거 없이 원단명을 붙이면 그게 곧 표시 위반이다. **원자료 확보가 선행 조건이다.**

### 3축 · 속성 = 필터 (Phase 1.5)

| 필터 | 소스 | 비고 |
|---|---|---|
| サイズ | 옵션 | **빅사이즈 298 을 여기로 흡수** — 일본에서 별도 카테고리는 정서적 저항 |
| カラー | 옵션 | 옵션값 정규화 선행 (`scripts/options.py`) |
| カップ | `custom.jp_size_map` | 상품팀 승인 후 |
| 免税区分 | `custom.duty_exempt_class` | **내부용.** 고객 노출은 별도 판단 |

### 교차 URL 규칙

```
/collections/modal              모달 전체
/collections/modal/bra          모달 × 브라     ← 태그 `bra`
/collections/heat/inner         발열 × 이너
```

상품에 **타입 태그를 1개씩** 부여한다 (`bra` `shorts` `inner` `leg` `homewear`).
카페24 태그는 이관하지 않으므로(P1-5) 태그 네임스페이스가 비어 있다 — 지금이 규칙을 세울 때다.

## 4. 일본 1차에서 접는 것

| 대상 | 판단 | 근거 |
|---|---|---|
| **서브브랜드 9종** | **접는다** | 일본 인지도 0. 상표 상태 미확인(`04` 16번). 축이 2개가 되면 51개 문제 재현 |
| DISNEY 512 | **금지** | 라이선스 지역 미확인 (`04` 3번) |
| 마리페 968 | 제외 | 한국 전용 프로모션 |
| 아울렛 297 | 제외 | 가격 앵커 훼손 |
| 빅사이즈 298 | **필터로 흡수** | 카테고리 분리는 정서적 저항 |
| 맨즈 327 | MVP 제외 | 여성 이너웨어 D2C 포지셔닝 |
| 베스트 291 계열 | **자동 컬렉션으로 전환** | 수기 관리 대상이 아니다 |

> 서브브랜드를 완전히 버리라는 뜻은 아니다. **상품명·상세에 남기고 축에서만 뺀다.**
> 일본에서 인지가 생기면 그때 컬렉션으로 승격한다. 순서가 반대면 빈 컬렉션만 늘어난다.

## 5. 자동화 — 수기 관리를 없앤다

| 컬렉션 | 방식 | 조건 |
|---|---|---|
| `new-arrivals` 新着 | 자동 | 생성일 최근 N일 |
| `bestsellers` ベストセラー | 자동 | 판매수 기준. **12개월 판매데이터 미확보 → 확보 후** |
| `back-in-stock` 再入荷 | 자동 | 재고 > 0 & 직전 0 |
| 타입 5종 | 자동 | `product_type` 조건 |
| 원단 4종 | 자동 | 메타필드 또는 태그 |

**수기 컬렉션은 편집 기획(`the-classics-collection` 자리)만 남긴다.**
카페24의 "주간베스트·리뷰베스트·인기PICK"을 사람이 채우던 방식은 이관하지 않는다.

## 6. 컬렉션 거버넌스 (Alo 의 `bras-1` 교훈)

Alo 에도 "Bras (old)"가 살아 있다. 규칙이 없으면 반드시 이렇게 된다.

1. **핸들은 영문 소문자·하이픈.** 한 번 정하면 바꾸지 않는다 (SEO·외부 링크).
2. **컬렉션 생성 요건**: 조건이 자동화 가능한가? 아니면 만들지 않는다.
3. **빈 컬렉션은 GNB 에 걸지 않는다.** (현재 `ホームウェア` 가 위반)
4. **폐기 시 삭제하지 말고 비공개 + 리디렉트.** 제목에 `(old)` 붙이고 방치 금지.
5. **분기 1회 점검**: 상품 0건 · 30일 무유입 컬렉션 목록화.

## 7. 단계별

**MVP (현재)**
- 타입 5종 컬렉션 — 완료 (`bra` 12 · `shorts` 7 · `inner` 12 · `leg` 9 · `homewear` 0)
- 타입 태그 부여 → 교차 URL 준비
- `new-arrivals` 자동 컬렉션
- `ホームウェア` 처리 결정

**Phase 1.5** (소재 조성비 확보 후)
- 원단 컬렉션 4종 + `/pages/fabric-guide` 해설 페이지
- 필터 (사이즈·컬러·컵)
- `bestsellers` (판매데이터 확보 후)

**Phase 2**
- 서브브랜드 승격 여부 재검토 (일본 인지도 · 상표 확인 후)
- 활동/용도 축 (`yoga` 자리) — 마른파이브 등가물은 **착용 상황**(オフィス/おやすみ/スポーツ)

## 8. 법령 주의 (`CLAUDE.md` §13)

원단 축은 **표시 리스크를 동반한다.** 전부 검토 필요 사항이며 법률 자문이 아니다.

- **인견** — 일본 품표상 `レーヨン` / `キュプラ` 중 무엇인지 특정 필요. 미특정 시 컬렉션 생성 보류
- **오가닉코튼** — 인증 근거 없이 표기하면 景表法 우량오인 소지. 인증서 확보 전 사용 금지
- **HEATTOUCH 発熱** — 효능 표현은 薬機法·景表法 검토 대상. `発熱` 대신 소재 사실 기술 우선
- **免税区分** 을 고객에게 노출할지는 별도 판단. 현재 값은 전부 「推定」이며 통관사 확정 전이다
