## 0. 결론

**컬렉션 4개로 시작한다. 그 외에는 만들지 않는다.**

```
브라 / 쇼츠 / 이너 / 레그
(ブラ / ショーツ / インナー / レッグ)
```

> 표기 규약: **한국어가 앞, 괄호가 실제 스토어 투입값(일본어)** 이다 (`CLAUDE.md` §13).

상품이 적을 때 구조를 많이 만들면 **빈 컬렉션이 생기고, 빈 컬렉션은 "물건이 없는 가게"로 읽힌다.**
이것이 초기 카탈로그의 가장 큰 리스크다. 내비게이션은 초기 전환율의 지렛대가 아니다.

**기준선: 컬렉션 하나에 상품 8~10개. 못 채우면 만들지 않는다.**

## 1. Alo Yoga 구조 — 그리고 왜 지금은 안 되는가

> **한계 명시**: 사이트 직접 접근이 네트워크에서 차단돼, 아래는 **컬렉션 URL 패턴과 검색 메타데이터**로
> 역추적한 것이다. 렌더된 메가메뉴를 본 것이 아니다. 메뉴 라벨·정렬은 재확인이 필요하다.

### 확인된 것

| 유형 | 핸들 | 성격 |
|---|---|---|
| 진입 | `shop-all` · `womens-shop-all` | 전체 (필터 전제) |
| 진입 | `new-arrivals` · `bestsellers` · `back-in-stock-2` | 판매 상태 |
| **원단** | `airbrush` · `alosoft` · `airlift` | franchise = 원단 |
| 편집 | `the-classics-collection` | 큐레이션 |
| 용도 | `yoga` | 활동 |
| 레거시 | `bras-1` (제목 "Bras (old)") | 폐기 미처리 |

세 가지 장치:

1. **원단이 1차 축** — `/pages/fabrication-guide` 해설 페이지가 축을 떠받친다
2. **상품 타입은 필터** — `shop-all?color=black&product-type=leggings`
3. **교차는 태그 경로** — `/collections/alosoft/leggings`, `/collections/airlift/shorts`
   Shopify 기본 기능 `/collections/{handle}/{tag}` 다. 앱도 커스텀 개발도 필요 없다

### 왜 지금 따라 하면 안 되는가

**Alo 의 구조는 SKU 가 수천 개라서 생긴 해법이다.** 고객이 다 볼 수 없으니 골라주는 장치가 필요하다.

MVP 는 41 SKU 다. 고객이 **전부 본다.** 여기에 원단 컬렉션 4개를 얹으면 하나당 4~5개가 들어간다.
화면이 빈다. 이건 큐레이션이 아니라 **재고 부족 신호**로 읽힌다.

> Alo 에 `bras-1` "Bras (old)" 가 살아 있는 것도 같은 이야기다.
> **컬렉션은 만들기는 쉽고 지우기는 어렵다.** 늘리기 전에 채울 수 있는지 먼저 본다.

**이 구조를 일본에 그대로 옮기면 안 되는 이유는 개수가 아니라 이 혼재다.**

## 3. MVP 구조

### 컬렉션 4개

| 핸들 | 한국어 | 투입값(일본어) | 현재 상품 수 | 구성 |
|---|---|---|---|---|
| `bra` | 브라 | ブラ | 12 | 브라 8 + 누드브라 4 |
| `inner` | 이너 | インナー | 12 | 캡나시 6 + FW 6 |
| `leg` | 레그 | レッグ | 9 | 스타킹·양말·레그워머 |
| `shorts` | 쇼츠 | ショーツ | 7 | 팬티 |
| ~~`homewear`~~ | ~~홈웨어~~ | ~~ホームウェア~~ | **0** | **메뉴에서 뺀다** |

`homewear` 컬렉션 자체는 남겨두되 **GNB 에서 제외**한다. 상품이 생기면 다시 건다.

### GNB

| 순서 | 한국어 | 투입값(일본어) | 성격 |
|---|---|---|---|
| 1 | 브라 | ブラ | 컬렉션 |
| 2 | 쇼츠 | ショーツ | 컬렉션 |
| 3 | 이너 | インナー | 컬렉션 |
| 4 | 레그 | レッグ | 컬렉션 |
| 5 | 사이즈 가이드 | サイズガイド | 페이지 — 상품이 아니라 **신뢰 근거** |
| 6 | 주문 조회 | 配送状況 | 링크 — 越境EC 문의 1위라 최상위 고정 |

### 만들지 않는 것 (지금은)

| 대상 | 이유 |
|---|---|
| 원단 컬렉션 (모달·코튼·심리스·발열) | 하나당 4~5개 → 빈 화면. 소재 조성비도 미확보(P0) |
| 필터 | 12개짜리 목록에 필터는 의미 없다 |
| 신상 (`新着`) | 41개가 전부 신상이다 |
| 베스트셀러 (`ベストセラー`) | 12개월 판매 데이터 미확보 |
| 서브브랜드 9종 | 일본 인지도 0 · 상표 상태 미확인(`04` 16번) |
| 빅사이즈 | 나중에 **필터로** 흡수. 별도 카테고리는 일본에서 정서적 저항 |
| DISNEY | **금지** — 라이선스 지역 미확인(`04` 3번) |
| 마리페 · 아울렛 · 맨즈 | 한국 전용 / 가격 앵커 훼손 / MVP 범위 밖 |

> 서브브랜드를 버리자는 게 아니다. **상품명·상세에는 남기고 축에서만 뺀다.**
> 일본에서 인지가 생기면 그때 컬렉션으로 승격한다. 순서가 반대면 빈 컬렉션만 늘어난다.

### 타입 태그 — 지금 해두면 좋은 유일한 것

상품마다 타입 태그를 1개씩 단다: `bra` `shorts` `inner` `leg` `homewear`

**지금은 효과가 없다.** 대신 나중에 원단 컬렉션을 만들 때
`/collections/modal/bra` 가 **개발 없이** 열린다 (Alo 의 3번 장치).
카페24 태그를 이관하지 않았으므로(P1-5) 태그 네임스페이스가 비어 있다 — 지금이 규칙을 세울 때다.

## 4. 상품이 늘면 — 켜는 순서

| 상품 수 | 켜는 것 | 조건 |
|---|---|---|
| **~50** | 컬렉션 4개. 그게 전부 | 현재 |
| 80~100 | **필터** (사이즈 · 컬러) | 목록이 한 화면을 넘기기 시작할 때 |
| 150+ | **원단 컬렉션** + 원단 해설 페이지 | 컬렉션당 10개 이상 채워질 때 · 소재 조성비 확보 후 |
| 200+ | **교차 URL** `/collections/{원단}/{타입}` | 타입 태그가 이미 달려 있으면 즉시 |
| — | 베스트셀러 (`ベストセラー`) | 12개월 판매 데이터 확보 후 (자동 컬렉션) |

**자동으로 만들 수 있는 것만 컬렉션으로 만든다.**
카페24의 "주간베스트·리뷰베스트·인기PICK"을 사람이 채우던 방식은 이관하지 않는다.

## 5. 컬렉션 규칙

1. **핸들은 영문 소문자·하이픈.** 한 번 정하면 바꾸지 않는다 (SEO·외부 링크)
2. **상품 8~10개를 못 채우면 만들지 않는다**
3. **빈 컬렉션은 GNB 에 걸지 않는다** (현재 홈웨어 `ホームウェア` 가 위반)
4. **자동화할 수 없는 조건이면 만들지 않는다** (편집 기획 컬렉션만 예외)
5. 폐기 시 삭제하지 말고 **비공개 + 리디렉트.** 제목에 `(old)` 붙이고 방치 금지
6. 분기 1회: 상품 0건 · 30일 무유입 컬렉션 목록화

## 6. 상품이 적을 때 실제로 힘 써야 할 곳

카테고리 구조는 **초기 전환율의 지렛대가 아니다.** 고객이 카탈로그를 다 보기 때문이다.
문제는 "어떻게 찾게 할까"가 아니라 **"왜 여기서 사야 하나"** 이고, 그 답은 상품 페이지에 있다.

| 우선순위 | 항목 | 상태 |
|---|---|---|
| 1 | 실측 사이즈표 (cm) | `04` 11번 미확보 |
| 2 | 소재 조성 · 취급표시 | `04` 10번 미확보 (家表法 필수) |
| 3 | 착용감 지표 | `custom.fit_index` 정의만 있고 값 없음 |
| 4 | 관세·배송 고지 | 페이지 골격만 있음 |
| 5 | 일본어 상품명·카피 | 미작성 → 전 상품 DRAFT |

> 문서·대화에서는 한국어로 적되, **스토어에 실제로 들어가는 값은 일본어**다 (`CLAUDE.md` §13).

**전부 원자료가 없어서 막혀 있다.** 컬렉션을 더 만드는 것보다 이쪽이 훨씬 크게 움직인다.

## 7. 일본 법령 주의 (`CLAUDE.md` §13)

원단 축을 켤 때 함께 걸리는 것들이다. 전부 검토 필요 사항이며 법률 자문이 아니다.

- **인견** — 일본 품표상 `レーヨン` / `キュプラ` 중 무엇인지 특정 필요. 미특정 시 컬렉션 생성 보류
- **오가닉코튼** — 인증 근거 없이 표기하면 景表法 우량오인 소지. 인증서 확보 전 사용 금지
- **HEATTOUCH 発熱** — 효능 표현은 薬機法·景表法 검토 대상. 소재 사실 기술을 우선
- **免税区分** 고객 노출 여부는 별도 판단. 현재 값은 전부 「推定」이며 통관사 확정 전이다
