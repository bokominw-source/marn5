# 03 · 일본 관세 · 소비세 (크로스보더)

> 공개 자료 기준 정리이며 법률 자문이 아니다. 통관사·세리사 확인 필수.

## 계산 구조

```
課税価格 → 関税 = 課税価格 × 세율
        → 消費税 = (課税価格 + 関税, 1000엔 미만 절사) × 7.8%
        → 地方消費税 = 消費税 × 22/78          (합계 ≒ 10%)
```

소비세가 관세를 더한 금액에 붙으므로 **관세율 10%면 실효 부담 ≒ 21%**.

**과세가격**: 상업수입 = CIF / 개인수입 = 해외 소매가 × 0.6 (0.6掛け 특례, **폐지 확정**)

## 소액수입 면세

- 課税価格 **합계** 1만엔 이하 → 관세·소비세 면제
- 단 **제외 품목은 금액과 무관하게 과세**

### 제외 품목 (関税定率法施行令 16조의3) × 마른파이브

**과세(제외)**
- 61.01~61.10 — 니트 팬티·슬립·파자마(6108), 탱크탑·T셔츠(6109), 니트 홈웨어
- 61.11 중 팬티스타킹·타이츠
- 61.12~61.14 — 수영복·트랙수트

- 6401~6405 (신발), 4202/4203 (가죽 가방·장갑)

**면세 가능**
- **브라·거들·보정속옷 (6212)** — 62류 의류는 제외목록에 없음
- **일반 양말 (6115.9x)**
- **우븐 홈웨어 (62류)**

→ MVP 41개 기준 **면세 가능 16 : 면세 제외 25 (61%)**

## 직배송 vs 3PL

| | 직배송 (소비자=수입자) | 일본 3PL (판매자=수입자) |
|---|---|---|
| 과세가격 | 소매가(×0.6) | CIF/이전가격 → 훨씬 낮음 |
| 1만엔 면세 | 적용 가능 (제외품목 주의) | 불가 |
| 수입소비세 | **회수 불가, 순비용** | **JCT 등록 시 매입세액공제로 전액 회수** |
| 실질 부담 | 관세 + 소비세 | 사실상 관세만 |
| 전제 | 없음 | 3PL · IOR(비거주자면 税関事務管理人) · JCT · 초도재고 · 일본어 품질표시 |

세금만 보면 3PL 압도적 우위. **MVP 직배송(DDP)으로 검증 → Phase 2 3PL.**

## 계산 예시 (관세 10% 가정)

| 케이스 | 고객 부담 |
|---|---|
| 니트 팬티 ¥9,000 직배송 · 0.6 적용 | 관세 540 + 소비세 500 ≒ **¥1,040** |
| 동일 · 0.6 폐지 후 | 관세 900 + 소비세 900 ≒ **¥1,800** (약 1.7배) |
| 브라 ¥9,000 직배송 (6212, 1만엔 이하) | **¥0** |
| 니트 팬티 3PL (이전가 ¥3,000) | 관세 ≒300, 소비세는 매입세액공제 회수 → **¥0** |
